# PDF-Password-Cracking-w-JTR-and-NW-Tools
I have learned and acquired the skill of cracking a password for a pdf document using John The Ripper. This required the extraction of a hash and feeding it into JTR and then cracking the password. This was part of my Week 3 project of the Cyber Security Internship with Network Walks where I also learned the setup of JTR and the use of NW tools too.

NW Tools are web based password cracking tools on NetworkWalks.com which allow you to extract the hash of a locked document and also
allow you to break the code of the hash that you extract. This skill is not only about cracking a password for a pdf file but also for
any type of file. I have also learned how you can use the hash to crack the password of anything like a social media account.
